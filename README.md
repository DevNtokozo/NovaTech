# NovaTech Solutions – Landing Page

A modern, responsive company landing page built with **React, Vite, and Tailwind CSS v4**.

## Features

- Responsive design for mobile and desktop
- Modern technology-focused UI
- Hero and About sections
- Services section
- Development process
- Company statistics
- Client testimonials
- Call-to-action section
- Contact form
- Responsive navigation and footer

## Technologies

- React
- Vite
- Tailwind CSS v4
- JavaScript
- Lucide React

## Installation

```bash
npm install
npm run dev
